# Literature Review

Approaches or solutions that have been tried before on similar projects.

**Summary of Each Work**:

- **Source 1**: [Attention Is All You Need]

  - **[Link](https://arxiv.org/abs/1706.03762)**
  - **Objective**: </br>This paper introduces the Transformer architecture in the initial Encoder-Decoder approach with Multi-Head attention
  - **Methods**: </br>The attention mechanism is introduced as a way to analyze realations across the complete seqeunce used as input data.
  - **Outcomes**: </br>The attention mechanism allows to model long-range dependencies and also to parallelize the training process, but without further restrctions, it scales quadratic with the length of the sequence.
  - **Relation to the Project**: </br>The input data for the project is inherently sequential with an a priori unknown range of the dependencies. Therefore, the Transformer architecture appears to be a sensible choice for the data at hand.

- **Source 2**: [GraphCast: Learning skillful medium-range global weather forecasting]

  - **[Link](https://arxiv.org/abs/2212.12794)**
  - **Objective**: </br>The authors propose a 2D-GNN (Graph Neural Network) to model the global weather. While the horizontal dimension is modelled by means of a "multi-mesh" (derived from icosahedral meshes of increasing resolution), the vertical dimension is collapsed into a single node on the horizontal graph.
  - **Methods**: </br>Using the two most recent states ($S_{-1}$ and $S_{0}$), the model uses Residual Learning to predict the delta required to compute $S_{1} = S_{0} + \Delta S$
  - **Outcomes**: </br>GraphCast is able to produce accurate prediction at a fraction of the computational cost of NWP (Numerical Weather Prediction), but struggles to predict the increasing uncertainty at longer lead times, that is present in ensemble-based NWP setups.
  - **Relation to the Project**: </br>When the paper was publishes, GraphCast was a state-or-the-art model in the context of MLWP (Machine Learning Weather Prediction). The use of a graph structure to introduce an inductive bias in the spatial domain appears to be instructive, as weather is also governed by non-local processes. As Transformers can be thought of as GNNs on a fully-connected graph ([Source](https://www.youtube.com/watch?v=8owQBFAHw7E&t=1493s)), the combination of the Transformer-based approach with the strucutral inductive bias of a graph seems to be an approriate choice for MLWP.

- **Source 3**: [UvA DL Notebooks - Deep Learning 1 (PyTorch) - Tutorial 6: Transformers and Multi-Head Attention]

  - **[Link](https://uvadlc-notebooks.readthedocs.io/en/latest/tutorial_notebooks/tutorial6/Transformers_and_MHAttention.html)**
  - **Objective**: </br>This notebooks describes the Transformer architecture in detail and provides a pratical impementation of **Source 1**. 
  - **Methods**: </br>This notebooks uses PyTorch for the deign of the Transformer.
  - **Outcomes**: </br>Demonstrates that a modular implementation of Multi-Head Attention and Positional Encodings is robust and scalable for various sequence tasks.
  - **Relation to the Project**: </br>The goal of the project is to design a Transformer-based model to enhance predictions generated by traditional NWP models. This notebook procides a great resource for the initial implementation of the model.
